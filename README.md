# Student Task Manager

## About the Project
Student Task Manager is a web application designed to help students organize their academic tasks, manage assignments, and track their progress.

## Features
- Add new tasks and assignments.
- View all tasks in one place.
- Mark tasks as completed.
- Delete tasks that are no longer needed.
- View the total number of tasks, pending tasks, and completed tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## How to Use
1. Open the application in your browser.
2. Enter a task in the input field.
3. Click the Add Task button.
4. Use the checkbox to mark a task as completed.
5. Click Delete to remove a task.
